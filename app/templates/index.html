ABOUT THIS PROJECT

SWD, Kwara State Polytechnic

The Software Development Team, Department of Computing, Kwara State Polytechnic brings computing students together to develop technical skills, collaborate on projects, and build professional networks. This academic portal is a student-focused software development initiative by the HND II 2026/2027 Group C at Kwara State Polytechnic, Ilorin.

Our project supports access to course information, departmental announcements and published academic calendar events in one convenient place.
